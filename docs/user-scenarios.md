## 유저 시나리오

> 1. 여수민(25세)은 퇴근 후 수영을 즐기는 직장인이다. 오늘 처음으로 1500m를 완영했고, 이 기쁨을 같은 취미를 가진 사람들과 나누고 싶다.
> 2. 앱을 열어 로그인한 뒤 게시글 작성 버튼을 누른다. "드디어 1500m 완영!" 이라는 제목으로 오늘의 느낌을 적고, 수영장에서 찍은 사진을 첨부해 게시글을 올린다.
> 3. 잠시 후 목록 화면을 새로고침하니 자신의 글에 좋아요가 3개 달려 있고, "저도 목표가 1500m예요!" 라는 댓글이 달렸다. 여수민은 댓글에 답글을 달며 같은 목표를 가진 사람과 연결된 느낌을 받는다.
> 4. 다음 날 자신의 프로필에서 "내 게시글" 목록을 확인하며 그동안의 수영 기록을 돌아본다.
