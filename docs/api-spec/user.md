## 요약

| 메서드 | 엔드포인트       | 설명      | 인증 |
|-----|-------------|---------|----|
| GET | `/users/me` | 내 정보 조회 | ✅  |

## 내 정보 조회

### 요청

```
GET /api/v1/users/me
Authorization: Bearer {{token}}
```

### 응답

```
200 OK

{
  "userId": 1,
  "email": "aaa@naver.com"
}
```

### 에러

| 상태  | 상황                                |
|-----|-----------------------------------|
| 401 | Authorization 헤더 없음 / 토큰 만료 · 위변조 |
| 404 | 토큰의 유저가 존재하지 않음                   |
