# 에러 코드 목록

## 400 Bad Request

* **의미:** 요청 데이터 형식/문법 오류
* **상황:** 필수값 누락, 입력값 유효성 검증(`@Valid`) 실패, 잘못된 JSON 형식

## 401 Unauthorized

* **의미:** 인증 실패 (로그인 필요)
* **상황:** 토큰 누락, 토큰 만료/위조, 로그인 정보 불일치

## 403 Forbidden

* **의미:** 권한 부족 (인가 실패)
* **상황:** 일반 유저의 관리자 페이지 접근, 남의 글 수정/삭제 시도

## 404 Not Found

* **의미:** 리소스 없음
* **상황:** 잘못된 API URL, DB에 존재하지 않는 ID(유저, 게시글 등) 조회

## 409 Conflict

* **의미:** 리소스 상태 충돌
* **상황:** 이메일/닉네임 중복, 이미 취소된 주문 재취소 등 비즈니스 정합성 위배
