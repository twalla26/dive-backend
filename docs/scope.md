# Dive 서비스 기능 구현 범위

| 구현 단계                    | 기능 분류    | 세부 기능 명세                   |

|                          | 커뮤니티 | 게시글 CRUD, 페이지네이션, 내 게시글 조회 |

| Phase 3: 제외 | 인게이지먼트   | FCM 기반 푸시 알림               |
