# 검증 규칙 표

| 검증 레벨       | 검증 대상 (Rule)                   | 주요 처리 계층               |
|-------------|--------------------------------|------------------------|
| **타입 & 구조** | JSON 파싱 오류, 데이터 타입 불일치         | Framework / Controller |
| **필수값**     | 필드 누락, Null, 빈 문자열, 공백         | DTO                    |
| **포맷 & 형식** | 이메일, 전화번호, UUID, 날짜 포맷         | DTO                    |
| **범위 & 길이** | 글자 수 제한, 최소/최대 금액, 페이징 크기      | DTO                    |
| **단순 상관관계** | 시작일 $\le$ 종료일, 비밀번호 확인 일치      | DTO / Value Object     |
| **도메인 불변식** | 객체 자체의 무결성 (예: 포인트 잔액 $\ge$ 0) | Domain Entity / VO     |
| **인증 (신원)** | 토큰 누락, 토큰 만료, 서명 불일치           | Security Filter        |
| **인가 (권한)** | 리소스 접근 권한 부족, 타인 데이터 수정 시도     | Security / Service     |
| **존재 여부**   | 요청한 식별자(ID)에 해당하는 리소스 부재       | Service                |
| **상태 충돌**   | 이메일/닉네임 중복, 이미 처리된 상태 변경 시도    | Service / DB           |
