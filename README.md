# 🌊 Dive (수영인 전용 Mini SNS)

> **"백엔드 기본기를 다지기 위한 기술 중심 프로젝트"**

## 📝 프로젝트 개요

'Dive'는 수영인들이 자신의 수영 일지를 기록하고 소통하는 SNS 서비스입니다. 본 프로젝트는 서비스 런칭 그 자체보다, **백엔드 엔지니어로서 탄탄한 기본기와 아키텍처 설계 능력을 기르는 것**을 최우선 목표로 합니다.

## 🎯 학습 목표 및 방향성

* **기술의 깊이:** 단순 구현을 넘어, 왜 이 기술을 선택했는지 근거를 확보하고 성능 최적화를 고민합니다.
* **직접 구현:** AI에 의존하지 않고 지저분하더라도 직접 코드를 작성하며, 이후 AI 리뷰를 통해 더 나은 코드를 찾아가는 반복 과정을 거칩니다.
* **기본기 다지기:** RDBMS 설계, 인덱싱 전략, 인증/인가 등 백엔드 근간이 되는 기술을 딥다이브합니다.

## 🛠 Tech Stack

* **Backend:** Java 25, Spring Boot, Spring Data JPA
* **Database:** MySQL
* **Frontend:** React (Vite 기반, CSR)
* **Tooling:** Postman, Actuator (모니터링)

## 📌 주요 개발 범위 (Scope Cut)

| 단계 | 기능 분류 | 세부 기능 |
| --- | --- | --- |
| **Phase 1 (필수)** | 회원/인증, 커뮤니티, 소통 | 회원가입/로그인, 게시글 CRUD, 페이지네이션, 댓글/좋아요 |
| **Phase 2 (선택)** | 소셜, 탐색 | 팔로우/언팔로우, 팔로잉 피드, 검색 |
| **Phase 3 (제외)** | 인게이지먼트, 추천 | FCM 알림, 인기글 로직 (오버스펙 방지 및 기본기 집중) |
